# Challenge 07: N-Tree

Aplicacion Angular para construir y recorrer un arbol n-ario.

## Ejecutar

```bash
npm install
npm start
```

Abre `http://localhost:4200/`. La pagina principal muestra la consola y el menu jerarquico conectados al mismo arbol.

## Funciones

- Insertar un nodo indicando el valor de su padre.
- Imprimir recorridos DFS y BFS en la consola del navegador.
- Buscar nodos por valor.
- Explorar las rutas `/menu-console` y `/sidebar-menu`.

## Validar

```bash
npm test
npm run build
```

# 01-ARRAYS

## Descripción
Proyecto educativo en HTML, CSS y JavaScript para probar las funciones principales de los arrays en JS.  
Cada método tiene su propio bloque con explicación, inputs para ingresar datos y un botón para ejecutar la función.

## Estructura
/Homework
-index.html   # Bloques de cada función
-style.css    # Estilos
-script.js    # Lógica de ejecución


## Funciones incluidas
- Iteración: `map`, `filter`, `reduce`, `forEach`
- Búsqueda: `find`, `findIndex`, `some`, `every`, `includes`, `indexOf`, `lastIndexOf`
- Manipulación: `push`, `pop`, `shift`, `unshift`, `concat`, `slice`, `splice`, `sort`, `reverse`, `join`
- Estructuración: `flat`, `flatMap`

## Uso
1. Clona el repositorio o descarga los archivos.
2. Abre `index.html` en tu navegador.
3. Ingresa un arreglo y parámetros en los campos de cada bloque.
4. Haz clic en **Procesar** para ver el resultado.

## Ejemplo
En el bloque de `map()`:
- Input: `[1,2,3]`
- Expresión: `x*2`
- Resultado: `[2,4,6]`

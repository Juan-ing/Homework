Laboratorio de Funciones de Arrays en JavaScript

map()

Transforma cada elemento y devuelve un nuevo arreglo.

filter()

Devuelve los elementos que cumplen una condición.

reduce()

Reduce el arreglo a un solo valor acumulando.

forEach()

Ejecuta una función en cada elemento (no devuelve nada).

find()

Devuelve el primer elemento que cumple la condición.

findIndex()

Devuelve el índice del primer elemento que cumple la condición.

some()

Devuelve true si algún elemento cumple la condición.

every()

Devuelve true si todos los elementos cumplen la condición.

push()

Añade elementos al final.

pop()

Elimina el último elemento.

shift()

Elimina el primer elemento.

unshift()

Añade elementos al inicio.

concat()

Concatena dos arreglos.

slice()

Devuelve una copia parcial del arreglo.

splice()

Agrega o elimina elementos en una posición.

sort()

Ordena los elementos.

reverse()

Invierte el orden de los elementos.

join()

Une los elementos en un string.

includes()

Verifica si un valor está en el arreglo.
